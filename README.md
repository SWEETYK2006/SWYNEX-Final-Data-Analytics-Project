# SWYNEX Final Data Analytics Project

## 1. Project Overview

This project presents a complete data analytics case study based on café transaction data. The project combines data cleaning, exploratory data analysis, interactive dashboard development, and business insights to understand sales performance and customer transaction patterns.

The project was completed as part of the SWYNEX Data Analytics Internship.

---

## 2. Problem Statement

The café has a large amount of transaction data, but raw transaction data alone does not provide clear information about sales performance, product demand, payment preferences, location performance, or sales trends.

The objective of this project is to transform the raw transaction data into meaningful information through data cleaning, analysis, visualization, and an interactive dashboard to support data-driven business decisions.

---

## 3. Project Objectives

* Clean and prepare the raw transaction dataset.
* Explore sales and transaction patterns.
* Identify high-performing products.
* Analyse payment methods and locations.
* Analyse sales trends over time.
* Build an interactive dashboard.
* Generate meaningful business insights from the analysis.

---

## 4. Dataset Information

The dataset contains café transaction records.

### Dataset Size

* **Number of transactions:** 10,000
* **Number of columns:** 8

### Dataset Columns

| Column           | Description                            |
| ---------------- | -------------------------------------- |
| Transaction ID   | Unique identifier for each transaction |
| Item             | Product purchased                      |
| Quantity         | Number of units purchased              |
| Price Per Unit   | Price of one unit                      |
| Total Spent      | Total amount spent in the transaction  |
| Payment Method   | Payment method used                    |
| Location         | Location of the transaction            |
| Transaction Date | Date of the transaction                |

---

## 5. Data Cleaning and Preparation

The raw dataset was reviewed and prepared before performing the analysis.

The cleaning and preparation process included:

* Checking the dataset structure and data types.
* Identifying missing values.
* Reviewing categorical fields such as Item, Payment Method, and Location.
* Checking the Transaction Date field.
* Reviewing numerical fields such as Quantity, Price Per Unit, and Total Spent.
* Preparing a cleaned dataset for further analysis.

The cleaned dataset was then used for exploratory data analysis and dashboard development.

---

## 6. Exploratory Data Analysis

Exploratory Data Analysis (EDA) was performed to understand the main patterns in the café transaction data.

The analysis focused on:

* Overall sales performance.
* Product-level sales.
* Payment method usage.
* Location-level performance.
* Monthly sales trends.
* Transaction and quantity patterns.

### Key Results

* **Total Sales:** ₹84,763.50
* **Total Quantity:** 28,834
* **Number of Transactions:** 10,000
* **Average Transaction Value:** approximately ₹8.98

### Top Products by Sales

| Product  |   Sales |
| -------- | ------: |
| Salad    | ₹16,605 |
| Sandwich | ₹12,956 |
| Smoothie | ₹12,556 |

The analysis also included visualizations for item performance, payment methods, locations, sales by item, and monthly sales trends.

---

## 7. Interactive Dashboard

An interactive dashboard was created to provide a visual summary of the analysed café transaction data.

The dashboard presents important performance indicators and visualizations, including:

* Total Sales
* Total Quantity
* Number of Transactions
* Average Transaction Value
* Sales by Item
* Payment Method Analysis
* Location Analysis
* Sales Trends

The dashboard allows the analysed data to be viewed in a more interactive and user-friendly format.

---

## 8. Key Business Insights

### 1. High-performing products

Salad generated the highest sales among the analysed products. This indicates strong customer demand and provides an opportunity for the café to maintain availability and consider suitable promotional strategies for high-performing products.

### 2. Payment preferences

The analysis shows different levels of usage across payment methods. Understanding these preferences can help the café maintain convenient and commonly used payment options for customers.

### 3. Location performance

Sales performance varies across locations. Location-level analysis can help identify stronger-performing areas and areas that may require additional attention or promotional activities.

### 4. Sales trends

Monthly sales analysis shows variation over time. Historical sales patterns can help the café plan inventory, staffing, and promotional activities more effectively.

### 5. Data-driven decision making

The dashboard combines key performance indicators and visual analysis in one place, making it easier to monitor sales performance and identify useful business patterns.
