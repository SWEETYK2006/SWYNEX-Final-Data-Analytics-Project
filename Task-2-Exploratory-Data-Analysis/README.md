# Task 2 - Exploratory Data Analysis

This folder contains the Exploratory Data Analysis (EDA) performed on the cleaned café transaction dataset.

## Analysis Performed

The analysis explored:

* Overall sales performance
* Item-level sales
* Payment method distribution
* Location-level performance
* Monthly sales trends
* Quantity and transaction patterns

## Key Results

* **Total Sales:** ₹84,763.50
* **Total Quantity:** 28,834
* **Number of Transactions:** 10,000
* **Average Transaction Value:** approximately ₹8.98

## Top Products by Sales

* **Salad:** ₹16,605
* **Sandwich:** ₹12,956
* **Smoothie:** ₹12,556

The EDA helped identify important patterns in product performance, payment methods, locations, and sales trends. These findings were later used to support the interactive dashboard and final business insights.
