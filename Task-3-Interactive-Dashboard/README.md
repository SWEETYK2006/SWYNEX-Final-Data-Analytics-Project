# Task 3 - Interactive Dashboard

An interactive dashboard was created using Looker Studio to provide a visual overview of the café transaction dataset.

## Dashboard Components

The dashboard includes:

* Total Sales
* Total Quantity
* Number of Transactions
* Average Transaction Value
* Sales by Item
* Payment Method Analysis
* Location Analysis
* Sales Trend

## Purpose

The dashboard brings the key findings from the exploratory data analysis into an interactive visual format.

It helps users quickly understand overall sales performance, product performance, payment preferences, location-level patterns, and sales trends.

## Tool Used

**Looker Studio**

The dashboard was developed as an alternative BI solution for presenting the analysed dataset interactively.
